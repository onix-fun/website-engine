# Дизайн-система админки

Дата: 2026-11-02. Общие UI-токены находятся в `frontend/src/index.css`, Tailwind сопоставляет их семантическим классам. Публичный runtime сохраняет отдельный визуальный слой.

## Направление

Монохромный интерфейс для ежедневной операционной работы: белые и серые поверхности, нейтральная навигация и контрастные чёрно-белые основные действия. Иерархия строится на тексте, плотности и разделителях, а не на тенях или карточках внутри карточек. Цвет остаётся только семантическим сигналом: красный для ошибок, зелёный для успеха, жёлтый для предупреждений и процессов.

## Семантические цветовые роли

HSL-переменные из `:root` и `.light`:

| Роль | Значение | Назначение |
| --- | --- | --- |
| background / foreground | `0 0% 97%` / `0 0% 12%` | Фон страницы и основной текст |
| card / card-foreground | `0 0% 100%` / `0 0% 12%` | Карточки, диалоги и содержимое |
| primary / primary-foreground | `0 0% 14%` / белый | Основное действие и фокус |
| secondary / muted | `0 0% 92%` / `0 0% 95%` | Вторичные контролы и вспомогательные поверхности |
| border / input / ring | `0 0% 86%` / `0 0% 80%` / `0 0% 38%` | Разделители, поля, клавиатурный фокус |
| success / warning / destructive | зелёный / жёлтый / красный | Успех, предупреждения/процесс, ошибка |
| info | `0 0% 38%` | Нейтральная информационная подсказка |
| sidebar | `0 0% 99%` | Светлая нейтральная навигация |

Тёмный режим использует ту же монохромную структуру: background `0 0% 8%`, card `0 0% 11%`, светлый нейтральный primary и почти чёрный sidebar. Семантические роли успеха, предупреждения и ошибки остаются цветными и контрастируются для тёмного фона. Темы light, dark и system синхронизированы через `ThemeProvider` и системный `prefers-color-scheme`.

Все контрастные пары и цветовые статусы не измерялись автоматическим WCAG-аудитом; этот документ не является сертификатом соответствия.

## Типографика и ритм

- Семейство: `Inter`, fallback `SF Pro Text`, `Segoe UI`, `system-ui`, sans-serif.
- Числа используют tabular figures; заголовки балансируют перенос.
- Основной CMS-текст — `0.9375rem` с межстрочным интервалом `1.75rem`; заголовки — согласованная шкала 1–2rem.
- Базовый радиус — `0.75rem` (12px); поля, кнопки и небольшие элементы используют согласованные радиусы 8–10px.
- `page-grid`: горизонтальный padding 16px на узком экране, 24px начиная со `sm`, 36px с `lg`; вертикальные интервалы — 24/28/32px.

## Сетка и компоненты

- Верхняя панель — `3.75rem`; sidebar — `15.5rem`, компактное состояние — `4.25rem`; максимальная ширина контента — `100rem`.
- `surface-panel` задаёт базовую поверхность с тонкой границей; `surface-subtle` — приглушённый слой без дополнительной визуальной глубины. В редакторе токенов и списке переопределений вместо карточек используются строки с разделителями.
- Навигационные ссылки имеют высоту 36px; активный пункт получает спокойный фон и маркер primary.
- Таблицы прокручиваются горизонтально на узком экране, не расширяя root layout.
- Кнопки, поля, карточки и заголовки используют общие семантические токены.

## Редактор дизайн-системы сайта

Вкладки группируют токены по задачам: цвета, типографика, размеры и сетка, радиусы и границы, эффекты, шрифты и бренд. На экране остаётся одна выбранная категория, поэтому список проще сканировать. В каждой строке показываются название, CSS custom property, диапазон/единица при применимости и действие сброса. Числовые скаляры имеют отдельное поле и выбор единицы; сложные выражения `clamp()`, `min()` и подобные сохраняются целиком в CSS-поле.

Цвета редактируются текстовым CSS-значением и поддерживающими его controls. HEX, RGB и HSL преобразуются в формат нативного color input; прозрачность задаётся отдельно. Вкладка бренда содержит логотип, шрифтовые файлы и роли body/display/header/hero.

Встроенный предпросмотр удалён. Сохранённая тема вступает в силу на сайте после создания и развёртывания снапшота. Экран показывает номер ревизии, блокирует сохранение без изменений, позволяет сбросить отдельное значение и обрабатывает конфликт ревизии.

## Доступность, темы и движение

- `:focus-visible` использует двухпиксельное кольцо с отступом от поверхности.
- Для `prefers-reduced-motion: reduce` CSS сокращает transition, animation и плавную прокрутку.
- Для ссылок и ключевых полей задан `touch-action: manipulation`; coarse pointer увеличивает цели кнопок.
- Выбор темы хранится как `system`, `light` или `dark`; системная настройка обновляется в реальном времени.

## Ограничения

Часть экранов использует локальные Tailwind utilities. Работа не мигрировала каждую пару padding/radius в отдельный CSS-токен и не заменяла UI-библиотеку. Автоматические проверки контрастности всех страниц и формальная WCAG 2.2 AA оценка требуют отдельного прохода.
